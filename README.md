# Solar System 🪐

> An interactive 3D visualization of our solar system built with HTML, CSS, and JavaScript.

---

## 🎯 Features

- 🌌 **Realistic Orbits** - Planets orbit the sun with accurate relative speeds
- 🎨 **Beautiful Design** - Gradient backgrounds and glowing effects
- 🔍 **Interactive Controls** - Zoom in/out, pause/play animation
- 📱 **Responsive** - Works on desktop and mobile devices
- 🚀 **Planet Info** - Click on planets to learn facts

---

## 🪐 Planets Included

| Planet | Distance from Sun | Orbital Period | Fun Fact |
|--------|-------------------|----------------|----------|
| Mercury | 57.9M km | 88 days | Fastest planet |
| Venus | 108.2M km | 243 days | Hottest planet |
| Earth | 149.6M km | 365 days | Our home! |
| Mars | 227.9M km | 687 days | The Red Planet |
| Jupiter | 778.5M km | 12 years | Largest planet |
| Saturn | 1.4B km | 29 years | Beautiful rings |
| Uranus | 2.9B km | 84 years | Rotates sideways |
| Neptune | 4.5B km | 165 years | Windiest planet |

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Ankitavasudev/SolarSystem.git

# Navigate to directory
cd SolarSystem

# Open in browser
open index.html
```

---

## 🎮 Controls

- **Scroll** - Zoom in/out
- **Click Planet** - View planet information
- **Spacebar** - Pause/Play animation
- **R** - Reset view

---

## 🛠️ Tech Stack

- **HTML5** - Structure
- **CSS3** - Animations and styling
- **JavaScript** - Logic and interactivity
- **CSS Grid** - Layout
- **CSS Animations** - Orbital movements
